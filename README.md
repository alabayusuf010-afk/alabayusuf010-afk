Graduate researcher at UFLA (Federal University of Lavras, Brazil), School of Engineering (PPGESISA).

**What I work on**
- Machine learning for wireless networks: predicting immersive VR quality-of-experience from private 5G network metrics

- Computer vision: stereo vision, camera calibration, ORB tracking

**Selected repositories**
- [qoe-vr](https://github.com/alabayusuf010-afk/qoe-vr): Random Forest surrogate for VR QoE on a private 5G Standalone testbed (R2 = 0.87)

- [Calib3D_ORBTracker](https://github.com/alabayusuf010-afk/Calib3D_ORBTracker): ORB feature tracking with 3D camera calibration (C++)
- [StereoVision](https://github.com/alabayusuf010-afk/StereoVision): stereo vision and calibration project (Kotlin)
